# About This Portfolio

Hi, I'm **Anand** — a technical writer specializing in developer tools and SaaS products.

This site showcases writing samples built using a **docs-as-code** workflow: Markdown files, version control with Git, and automated publishing via GitHub Actions.

## My Approach

**Clarity first.** I write for developers who are busy and don't want to hunt for information. Every doc answers three questions: what is this, how do I use it, and what happens when it goes wrong.

**Docs-as-code.** Documentation lives alongside the product in Git, goes through review, and ships with the code. No stale PDFs.

**Structure over prose.** Tables, code blocks, and consistent heading hierarchies reduce cognitive load and make scanning fast.
